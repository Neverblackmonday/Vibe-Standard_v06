# REQ-003: 표준 업데이트용 원클릭 마우스 복붙 패키지(Update_Package) 구축

## 1. 요청 원문
> "만약 표준화 자료가 업데이트되면 어떡하지? 간단하게 복붙으로 업데이트 가능하도록 폴더구성이나 뭐나 가능하나? 내생각엔 방법 B가 나은 듯. REQ 003으로 작성해." (2026-10-06 13:55 KST)

## 2. 배경 및 목적
- **배경**:
  - `Vibe Standard` 프레임워크가 지속적으로 기능 개선 및 판올림(`v02 → v02.1 → v03`)될 때, 이미 이 표준을 복제하여 실무 프로젝트를 개발 중인 수많은 저장소가 존재하게 됩니다.
  - 표준이 업데이트될 때마다 수동으로 파일을 일일이 골라서 복사하거나 명령어를 치는 방식은 휴먼 에러를 유발하고, 자칫 고객이 개발 중인 제품 소스코드나 기획 문서를 덮어써서 날려버릴 치명적 위험이 있습니다.
- **목적**:
  1. **고객 자산 100% 무손실 보존**:
     - 개별 프로젝트의 제품 소스코드(`assets/src/`), 테스트(`assets/tests/`), 제품 명세(`Design/docs/prd/`, `tad/`), 안건/판정 이력(`REQ`, `RP`, `RES`), 대표님 자료(`CEO/References/`)는 0.1%도 건드리지 않는 완벽한 안전 격리 설계.
  2. **초간편 마우스 드래그 '복붙(Ctrl+C / Ctrl+V)' 업데이트 실현 (방법 B)**:
     - 배포본에 **`Update_Package/`** 폴더를 독립 제공하여, 고객이나 대표님이 탐색기에서 내부 파일을 전체 선택(`Ctrl+A`)하고 기존 프로젝트 루트에 덮어쓰기(`Ctrl+V`)만 누르면 1초 만에 최신 표준으로 업데이트되는 체계 구축.
  3. **업데이트 패키지 자동 생성 빌더 개발**:
     - 표준 저장소에서 최신 표준 파일들만 추출하여 `Update_Package/` 구조로 안전하게 번들링하는 자동화 스크립트 개발.

## 3. 세부 설계 및 작업 범위

### 3.1 `Update_Package/` 배포 구조 설계 - [설계팀 담당]
기존 프로젝트 루트에 그대로 덮어썼을 때 고객 구역과 충돌하지 않도록 완벽한 1:1 거울(Mirror) 구조로 구성합니다.
```text
Update_Package/
  ├── Workflow/                        ──▶ 표준 공식 매뉴얼 7종 일괄 갱신
  ├── AGENTS.md                        ──▶ 최신 거버넌스 헌장 갱신
  ├── CLAUDE.md                        ──▶ 최신 Claude 연동 규칙 갱신
  ├── setup.cmd                        ──▶ 최신 초기화 배치 파일 갱신
  ├── .gitattributes                   ──▶ 최신 Git 속성 규칙 갱신
  ├── .claude/
  │     ├── settings.json              ──▶ 최신 플랫폼 보안/권한 규칙 갱신
  │     └── agents/                    ──▶ 최신 7대 부서 서브에이전트 정의 갱신
  └── Departments/
        ├── Development/assets/scripts/
        │     └── check_standard.py    ──▶ 최신 무결성 검사 스크립트 갱신
        └── Standard_Templates/        ──▶ 부서별 최신 표준 템플릿(REQ, PRD, TAD, EC, HOTFIX, RES) 모음
```
※ 고객 제품 구역(`assets/src/`, `assets/tests/`, `Design/docs/prd/`, `tad/`, `CEO/`)은 패키지에 **폴더 자체가 존재하지 않으므로**, 덮어쓰기를 해도 고객 코드가 100% 안전하게 보존됩니다.

### 3.2 패키지 빌더 스크립트 개발 - [개발팀 담당]
- `Departments/Development/assets/scripts/build_update_package.py`:
  - 표준 저장소의 최신 파일들을 읽어 `Update_Package/` 디렉터리에 자동으로 거울 구조로 패키징하는 빌드 스크립트 구현.
  - 배포 대상 파일들의 누락 여부 및 한글 인코딩(UTF-8) 검증 로직 포함.

### 3.3 표준 업데이트 공식 매뉴얼 및 가이드 작성 - [설계팀 담당]
- `Workflow/01_vibe_standard_overview.md` 및 `Workflow/06`에 「표준 버전 업데이트 및 프로젝트 동기화 절차(방법 B 마우스 복붙 가이드)」 공식 등재.
