# REQ-006: 거버넌스 헌장(AGENTS.md) 및 7대 Workflow 매뉴얼 중복 수술·SSOT 재구축과 전역 문체 전수 정비

## 1. 요청 원문
> 1. 그 외 오탈자, 부적절한 말투와 어휘 점검하고 보고해라.
> 2. AGENTS.md에 자꾸 하위문서들이랑 중복되는 내용들이 있는데, 왜 굳이 AGENTS.md에 한번 더 적어놓은거임? 이거 SSOT 안지켜지면 어쩔라고?
> 3. 과제 5에 AGENTS.md 뿐만 아니라, Workflow 문서들도 포함임. 전체적으로 다 훑어보고, SSOT 살리고 통폐합 또는 재구성안 제출해라.
> 4. 과제 4,5는 따로 REQ006으로 빼자.
> 5. REQ 005는 Major, REQ 006은 Critical. 그리고 4대가 아니고 7대 아님?

## 2. 배경 및 목적
- **배경**:
  - `Vibe Standard v02` 실무 운영 중, 상위 헌장(`AGENTS.md`)과 7대 매뉴얼(`Workflow/`) 간의 3중 중복 서술로 인해 단일 원천(SSOT) 원칙이 훼손되고 매뉴얼 개정 시 헌장 수정 누락이 반복 발생함.
  - 대표님의 지시에 따라 7대 매뉴얼 체계(`Workflow/01~07`)는 그대로 유지하되, 내부의 불필요한 중복 절(Section)을 수술적으로 제거하여 각 문서가 고유 책무만 갖도록 정합화해야 함.
  - 전역 지침에 위배되는 사물 의인화 표현(예: "문서가 규칙을 기억한다", "검사가 통과했다") 및 어색한 번역투가 일부 남아 있음.
- **목적**:
  1. `AGENTS.md`의 중복 서술을 전면 제거하고 100줄 이내의 최상위 불변 헌장으로 경량화(SSOT 단일 참조).
  2. `Workflow/` 7대 매뉴얼의 기존 체계(`01~07`)를 유지하면서, 각 문서 간 중복 절을 수술적으로 제거하여 **단일 원천(SSOT)** 확립.
  3. 저장소 전역 문서의 사물 의인화 및 번역투 표현을 성인 직장인 표준 문체로 전수 교정.

## 3. 세부 설계 및 3대 핵심 과제

### [과제 1] `Workflow/` 7대 매뉴얼 내부 중복 절 수술적 제거 및 고유 책임 일원화
- **정비 원칙**: 7대 매뉴얼 파일명(`01~07`)은 그대로 유지하되, 문서 간 겹치는 표와 절을 전면 삭제하고 단일 링크 참조로 대체.
  1. `Workflow/01_vibe_standard_overview.md`: 4절 저장소 구조 표(도메인 중복), 5절 업데이트 절차(06 중복) 제거 ──▶ 순수 표준 개요와 고객 공간 격리 원칙만 기술.
  2. `Workflow/02_5대_도메인_구조_및_역할.md`: `AGENTS.md`와의 중복 서술 제거 ──▶ 5대 도메인 및 감사실 고유 세부 작업 지침만 집중.
  3. `Workflow/03_라이프사이클_및_워크플로우.md`: 개념적 흐름 및 등급별 심사 기준에 집중 (실행 명령 하드코딩 제거).
  4. `Workflow/04_모델_운용_기준.md`: 모델 사양, effort, 타깃 컨텍스트 단일 원천 기술.
  5. `Workflow/05_비서실_클로드cli_인수인계_정책.md`: 비서실 CLI 인수인계 및 원스톱 실행 명령 단일 원천 기술.
  6. `Workflow/06_거버넌스_엔지니어링_아키텍처.md`: 보안 권한, 훅, 검사 스크립트, 배포/업데이트 패키징 기술적 메커니즘 집약.
  7. `Workflow/07_엔지니어링_변경통제_및_서식_명세.md`: 서식 본문 하드코딩 제거 ──▶ `Workflow/templates/` 링크 참조로 위임하고 순수 메타데이터/유효성 규격만 기술.

### [과제 2] `AGENTS.md` 중복 제거 및 최상위 헌장 슬림화 (SSOT)
- **개선책**:
  - `AGENTS.md` 내 세부 절차, 모델 규격, 템플릿 서식, 중복 표를 전면 제거.
  - 불변 원칙, 5대 도메인 권한 한계, 승인/보안 대원칙만 100줄 이내로 간결히 유지.
  - 모든 세부 실행 규칙은 7대 매뉴얼(`Workflow/01~07`)로 단일 원천 위임 참조.

### [과제 3] 전역 지침 기반 어휘·말투·의인화 전수 정비
- **개선책**:
  - 사물 의인화 표현 ──▶ 객관적 서술로 정비.
  - 어색한 번역투(분기, 갈래 등) 전수 점검 및 자연스러운 직장인 표현으로 교정.
