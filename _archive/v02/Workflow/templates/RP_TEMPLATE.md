# RP-001: 재작업 절차서 (Rework Procedure)

> 본 문서는 REQ/EC 동결 이후 진행 중(In-Flight) 인입된 대표님의 추가 지시를 동결된 원본 문서를 훼손하지 않고 공식 수용하여 품질팀의 1:1 대조 추적성을 보장하는 재작업 절차서입니다.

## 1. 대표님 추가 지시 원문
> 대표님의 추가 지시 원문을 원형 그대로 인용합니다.

## 2. 재작업 배경 및 원본 베이스라인 대조
- **관련 원본 안건**: `REQ-xxx`
- **관련 원본 EC**: `EC-xxx`
- **재작업 사유**: 안건 진행 도중 추가 요구사항 발생

## 3. 부서별 추가 작업 지침
| 부서 | 단계 | 작업 지침 요지 |
| :---: | :---: | :--- |
| **설계** | 1단계 | 추가 지시에 따른 명세 보완 |
| **개발** | 2단계 | 추가 지시에 따른 코드/스크립트 구현 |
| **품질** | 3단계 | 추가 지시 체크리스트 1:1 대조 판정 |

## 4. 추가 요구사항 검증 기준 (체크리스트)
- [ ] 1. 대표님 추가 지시 사항이 누락 없이 구현되었는가?
- [ ] 2. 동결된 원점 REQ의 핵심 목표와 모순되지 않는가?
- [ ] 3. 품질팀의 1:1 대조 검증을 통과하였는가?
