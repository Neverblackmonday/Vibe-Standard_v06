## 3. 공식 문서 확인 내용

v01 3절 F1~F12와 같다. 이 버전에서 다시 조회하지 않았다. 4절이 인용하는 항목만 요지를 다시 적는다.

- F2: 서브에이전트 모델은 ⓐ 호출마다 주는 `model` 인자 ⓑ 정의 파일 `model`(`inherit`는 주 대화 모델) ⓒ `CLAUDE_CODE_SUBAGENT_MODEL` ⓓ 주 대화 모델 순으로 정해진다.
- F3: 호출 인자나 정의 파일에 주 대화와 같은 계열의 별칭을 적으면 주 대화의 정확한 모델로 실행된다.
- F4: `CLAUDE_CODE_SUBAGENT_MODEL_FORCE`가 켜져 있으면 정의 파일 `model`이 무시되고 호출 인자를 줄 수 없다.
- F5: 대화형 세션의 `/tasks`가 실행 중 서브에이전트의 모델과 effort를 보여 준다.
- F7: 별칭은 시간이 지나며 최신 권장 버전으로 바뀌고, 버전을 고정하려면 전체 모델 ID를 쓴다.
- F9: 서브에이전트 정의 파일에 `effort`를 적을 수 있다. 정의 파일에 없을 때 세션 effort를 이어받는지는 문서에 없다.

## 5. 그 밖의 관찰과 확인하지 못한 항목

- `Agent` 호출 인자 `model`에 별칭(`sonnet`)을 준 경우만 시행했다. 모델 ID(예: `claude-sonnet-5-5`)를 직접 받는지는 확인 불가다.
- 시험 A의 별칭 `sonnet`은 `claude-sonnet-5-5`로 풀렸다(T19). 이 결과는 F7·F12(`sonnet` 별칭이 Sonnet 5.5를 가리킴)와 맞는다. 별칭은 시간이 지나며 가리키는 버전이 바뀐다(F7).
- 정의 파일 `model`에 모델 이름을 적었을 때의 동작, `CLAUDE_CODE_SUBAGENT_MODEL`·`_FORCE`의 값과 효과, 서브에이전트의 effort 상속, Claude Code 버전은 확인 불가다.
- 시험 A·B가 도구를 쓰지 않고 파일을 만들지 않았다는 것은 오케스트레이터 보고이며, 이 세션은 시험 A·B의 `.jsonl`에서 응답 행(T19·T20)만 대조했다.
- 시험 A·B와 실험 세션은 모두 D12 범위 안이다. 중급(Sonnet)만 썼고 최고급은 쓰지 않았다.
