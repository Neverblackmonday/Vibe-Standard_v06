# PM 지시문

> 비서실이 PM에 주는 지시를 만드는 틀이다. 규정의 원천은 `Workflow/05_인수인계_및_실행명령` 2절 「PM 지시문」 항이다.
> - 범위: `Workflow/05_인수인계_및_실행명령` 「실행 명령」의 형식과 표의 지시문에 아래 값만 채운 실행 명령 한 줄이다. 정지 조건·보고 방식·그 밖의 지시를 더하지 않는다.
> - 전달 방식: `Workflow/05_인수인계_및_실행명령` 2절의 서비스별 표를 따른다.
> - 원스톱 실행 명령은 REQ 6절 「실행 명령」의 명령과 같다.
> - PM 지시문은 파일로 저장하지 않는다. 이 안내문은 작성할 때 지운다.

## 채울 항목
- **명령 종류**: REQ 작성 명령 / 원스톱 실행 명령 가운데 하나
- **대상 파일**: REQ 작성 명령은 ORDER 경로, 원스톱 실행 명령은 REQ 경로
- **effort**: `Workflow/04_모델_운용` 「effort」를 따른다. `high` 이상은 REQ 결정 표에서 대표님이 승인한 경우에만 쓴다

## 완성한 명령

```bash
<`Workflow/05_인수인계_및_실행명령` 「실행 명령」의 형식과 표의 지시문에 위 값을 채운 한 줄>
```
