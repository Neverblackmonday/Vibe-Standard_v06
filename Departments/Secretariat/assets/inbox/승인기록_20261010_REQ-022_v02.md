D5 수정안은 다음과 같다. 등급별 기본 모델의 모델 ID를 표준 한 문서(이하 원천 문서)에만 적고, 실행 명령·서식·서브에이전트 정의가 원천 문서를 따르게 한다. 단계별 모델로 세션을 기동하는 PM 책임은 권고안대로 한다. 등급 배정은 그대로 두고, 등급별 기본 모델을 같은 모델의 더 새 버전으로 바꾸는 갱신(모델 ID만 바뀌는 갱신)은 ORDER·REQ를 거치지 않는다. 새 버전이 나오면 비서실이 새 모델 ID와 원천 문서의 고칠 위치를 대표님께 보고하고, 대표님이 원천 문서의 모델 ID를 직접 고친다(에이전트의 수정이 아니므로 `AGENTS.md` 「불변 원칙」 3항에 걸리지 않는다). 대표님은 같은 수정에서 원천 문서 개정 이력에 한 행을 더하며, 「안건」 열에는 `CEO`를, 「변경 요지」에는 바꾸기 전 모델 ID와 바꾼 뒤 모델 ID를 「이전 ID → 새 ID」 꼴로 적고, 리비전 태그는 붙이지도 지우지도 않는다. 이 예외는 `Workflow/07_문서_서식_및_번호` 4절에 둔다. 커밋은 대표님 요청으로 `AGENTS.md` 「불변 원칙」 5항의 판정 전제 제외 커밋(메시지 `[CEO]`)으로 하며, `--no-verify`가 필요하면 5항을 따른다. 갱신의 적용 시점(진행 중인 안건의 처리, D6 모델 대조의 기준)은 EC에서 정한다. 등급 배정이나 모델 계열을 바꾸는 변경은 권고안대로 ORDER·REQ로 한다. D13 수정안은 다음과 같다. 지금은 권고안대로 두 파이프라인의 모든 세션과 판정에 Claude Code에서 실행할 수 있는 모델만 쓰고, 등급표는 그대로 둔다. 이 모델 제한은 현행 실행 도구가 Claude Code라는 사유와 함께 `Workflow/` 안의 한 곳에만 적고, 다른 문서는 그곳을 참조한다. 다른 실행 도구(Codex 등)의 도입 여부와 방법, 그에 따른 `AGENTS.md` 「불변 원칙」 4항과 실행 명령 체계의 개정은 이 REQ에서 정하지 않고 뒤의 ORDER·REQ로 정한다.
