브리핑: 토큰 사용량 1주일 분석

Claude Code 전체 기록(10-06 00:38 ~ 10-13 09:57)과 코워크 사용 근거로 본 문제점, 원인, 개선안, 비포·애프터 (v02: 코워크 추가)

결론

  1. Claude Code는 1주일 동안 $931.76(API 환산)를 썼고, 사실상 전부 Opus였습니다. 비용의 60%가 서브에이전트에서 나왔습니다.
  2. 코워크도 Claude Code와 비슷하거나 더 많이 썼을 수 있습니다. 10-12 크레딧 $200 가운데 Claude Code는 $67.40이고 나머지 약 $132.60(66%)이 코워크 몫으로 추정됩니다. 이번 주 사용량 화면에서도 코워크가 57%입니다. 코워크 세션은 기동 맥락이 11.5만 토큰으로 Claude Code 본 세션(약 4.9만)의 2.3배입니다.
  3. Claude Code 개선안 다섯 가지를 함께 적용하면 Claude Code 비용을 약 30~34%(주 $280~315) 줄일 수 있다고 추정합니다. 코워크는 세션을 작업 단위로 끊고 문서 분량을 줄이는 개선안(C1~C4)을 제안하며, 절감액은 실측 뒤 정합니다.
