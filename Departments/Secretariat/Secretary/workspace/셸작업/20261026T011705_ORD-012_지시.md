## B단계(v06 루트에서 새로 시작한 세션)

실행 위치는 `D:/Vibe Coding/Vibe Standard_v06` 루트다. B단계의 `git` 명령은 이 폴더에서 실행한다.

B단계 문구 하나는 요청 커밋(B1), 브랜치·태그(B2), 요청 푸시(B3)를 함께 지시한 것이다. ### B1. 요청 커밋

### B3. 요청 푸시

v05 `Workflow/05` 8.3절 「요청 푸시」 절차를 실행한다. 원격 `origin`은 빈 저장소라서 절차 2)의 `git log --oneline origin/<브랜치>..HEAD`는 실행할 수 없다. 대신 0번에서 올릴 범위를 기록한다. 절차의 1)(푸시 전 시작 확인)과 4)(`git status -sb` 확인)는 그대로 한다.

0. 푸시 전에 아래 값을 기록한다.
   - `git rev-list --count master`
   - `git rev-list --max-parents=0 master`(루트 커밋)
   - `git rev-parse master`
   - `git rev-parse v06-main`
1. 실행 전에 대표님께 「GitHub 로그인 창이 뜰 수 있으니 직접 입력해 주십시오」라고 알린다. 시간 제한은 600000ms로 둔다.
2. 차례로 실행한다.
   - `git push -u origin master`
   - `git push origin v06-main`
   - `git push origin v04-final v05-final`
3. `git ls-remote origin`의 아래 값이 로컬 해시와 같은지 대조한다.
   - `refs/heads/master`
   - `refs/heads/v06-main`
   - `refs/tags/v04-final`
   - `refs/tags/v05-final`
4. 거부, 실패, 시간 초과는 멈출 조건이다.
