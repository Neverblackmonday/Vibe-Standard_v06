## 3. 시험 파일
> 해시는 `git diff --no-index --full-index /dev/null <파일>` 출력의 `index` 줄에서 `..` 뒤의 값이다. 최종 판정이 같은 명령으로 대조한다.

| 경로 | 해시 |
| :--- | :--- |
| `Departments/Quality/assets/acceptance/REQ-031_v01/test_req031.py` | `8bce7cf79d043c6b2c3949e308de498f3479a904` |
| `Departments/Quality/assets/acceptance/REQ-031_v01/conftest.py` | `844eec2564da45a1f39977606859214b8149567c` |
| `Departments/Quality/assets/acceptance/REQ-031_v01/pytest.ini` | `51d6907c5147efeb257d40dfa82a19352d1b9675` |

- 해시 조회: 저장소 루트에서 Bash 도구로 파일마다 `git diff --no-index --full-index /dev/null <파일>`(`test_req031.py`·`conftest.py`는 뒤에 `| grep ^index`)을 실행했다. 직후 PowerShell `Get-Date -Format "yyyy-MM-ddTHH:mm:sszzz"` 결과는 2026-10-15T15:24:14+09:00이다. 명령마다 Git이 `warning: in the working copy of '<파일>', LF will be replaced by CRLF the next time Git touches it`을 출력했다. 해시를 구한 뒤 시험 파일을 고치지 않았다.
- `pytest.ini`는 `addopts = -p no:cacheprovider`만 둔다(`ACC-029_v01` 3절과 같은 내용, 같은 해시).
- `conftest.py`의 `--acc-design-dir`, `--acc-dev-dir`, `--acc-dev-result`, `--acc-script`는 결함 사본으로 Red를 확인할 때만 쓰는 옵션이다. 현행 인수 시험 실행(구현 단계, 최종 판정)에서는 주지 않는다. 옵션이 없으면 시험은 개발·설계 적용본 폴더(`REQ-031_적용본_vNN`)의 가장 높은 버전, `DEV-031_vNN`의 가장 높은 버전, 저장소의 원본을 대상으로 한다.
- 시험은 저장소에서 파일을 읽고 `git ls-files`·`git status`를 조회만 한다. 임시 Git 저장소(1 ②, 3 ②, 19 ④)는 pytest `tmp_path` 아래에만 만든다.
