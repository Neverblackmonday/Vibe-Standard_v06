- 해시 조회 시각: 2026-10-10T21:50:40+09:00(직전 `date -Iseconds`) 뒤, 2026-10-10T21:51:09+09:00(직후 `date -Iseconds`) 앞. 저장소 루트에서 Bash 도구로 파일마다 `git diff --no-index --full-index /dev/null <파일>`을 실행했다. 명령마다 Git이 `warning: in the working copy of '<파일>', LF will be replaced by CRLF the next time Git touches it`을 출력했다. 파일 내용은 바뀌지 않는다. 해시는 4절의 모든 실행이 끝난 뒤의 파일 값이며, 이후 시험 파일을 고치지 않았다.
