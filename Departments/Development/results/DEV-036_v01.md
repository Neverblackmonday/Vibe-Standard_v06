- **훅 오류 표시**: 훅이 막으면 Claude Code는 도구 결과에 훅 명령 전체(7,737자의 이스케이프 문자열)를 먼저 보이고 그 뒤에 표준 오류를 보인다(3.2절). 실측 세션의 PM은 표준 오류의 사유와 조치를 읽고 보고했다.
- **최고급 모델 ID**: 1.1절 표에 없으므로 `fable` 계열의 동작은 시험값 `claude-fable-5-0`으로만 확인했다(3.1절 (6)(7)). 실제 최고급 모델 ID의 형식(조각에 `fable`이 있는지)은 확인 불가.

**실행하지 못한 명령**

없음. 권한 거부나 승인되지 않은 확인 요청으로 실행되지 않은 명령은 없었다. 작업 초기의 조회 명령 몇 개는 `Workflow/06_통제장치_및_배포` 「명령 형태」의 원리를 벗어난 형태(`cd "<저장소 루트>" && …`, `echo`를 묶음)로 실행했으며 모두 실행되었다. 그 실행에 권한 확인 요청이 있었는지는 이 세션에서 확인 불가다. 해당 명령의 결과는 위 표의 근거로 쓰지 않았다(같은 값을 원리 안의 명령이나 스크립트로 다시 얻었다).
