# 비밀정보 검출 예외 목록 (check_standard.py 순서 4와 --scan-all)
# 원천: Workflow/06_통제장치_및_배포 「비밀정보 검출」
#
# 형식
# - 빈 줄과 # 으로 시작하는 줄은 무시한다.
# - 항목 줄: <규칙 이름> <저장소 루트 기준 상대 경로>
#   첫 공백 앞이 규칙 이름(check_standard.py의 SECRET_RULES에 있는 이름)이고, 그 뒤 나머지 전체가 경로다.
#   항목은 그 경로 파일의 그 규칙 검출을 모두 뺀다. 경로는 정확히 같을 때만 맞고, 폴더·와일드카드는 쓰지 않는다.
# - 항목 바로 위 줄에 「# <등록 일자> <근거(대표님 직접 또는 REQ 번호)> <사유>」 주석을 둔다.
#
# 등록 주체
# - 대표님이 직접 등록하거나, REQ로 거버넌스 파일 개정 절차(Workflow/06 「거버넌스 파일 개정 절차」)를 거친다.
# - 비서실·PM·서브에이전트(에이전트)는 등록하지 않는다.
