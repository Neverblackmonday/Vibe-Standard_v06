# 검사 장치 대장

이 대장은 이 저장소의 검사 장치(기계 장치와 절차 장치) 목록이며 규칙의 원천이 아니다. 규칙은 행마다 적은 「규정 원천 절」을 따른다. 위치·형식과 관리 규칙(검사를 더하거나 바꾸는 안건은 EC(없으면 명세 단계 산출물)에서 이 대장으로 기존 장치와의 중복·경계를 확인하고, 그 안건의 적용본으로 이 대장을 고친다)은 `Workflow/06_통제장치_및_배포` 「검사 장치 대장」이 원천이다.

- 「규정 원천 절」의 번호는 `REQ-034` 반영 뒤 절 번호다. 「01」~「07」은 `Workflow/01_표준_개요.md`~`Workflow/07_문서_서식_및_번호.md`다.
- 「스크립트 폴더」는 `Departments/Development/Implementation/assets/scripts/`다.
- 근거 자료: `Departments/Secretariat/Secretary/assets/research/조사_20261016_검사장치전수점검_v01.md` 1절(M1~M7, P1~P9), `REQ-032` 요구 항목 20(M8~M11), 예정 장치는 ORD-012 요구 항목 4·7·11·16(F1~F4), F1의 현행화와 M12는 `REQ-033`(요구 항목 4·8), F2~F4의 현행화, M13·M14·P10과 M1·M2·M3·M10·P3·P6·F1의 변경은 `REQ-034`.
