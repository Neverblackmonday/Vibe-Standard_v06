## 6. 실험 결과 (실험 단계를 맡은 경우만)
> 뒤 단계에서 이 결과서의 다음 버전을 쓰면 이 절을 그대로 옮긴다(`Workflow/03_라이프사이클` 「실험 단계」). EC가 인용할 최종본은 이 절이다.

- **실험 목적**: 세션별 모델 지정과 실제 실행 모델 확인의 실측. ① 오케스트레이터와 다른 모델로 서브에이전트가 실행되는지 ② `model: inherit`의 상속 ③ 실행 모델을 확인하는 수단(REQ-022_v02 4절 「실험」 행, D5·D6·D12).
- **`Lab/` 경로**: `Lab/REQ-022_모델지정` (기록 파일 `Lab/REQ-022_모델지정/실험기록_v02.md`. 아래 T·F 번호는 이 파일과 `실험기록_v01.md`의 번호다)
- **요지**:
  - **① 다른 모델의 서브에이전트(실측)**: 정의 파일이 `model: inherit`인 `development` 서브에이전트를 오케스트레이터가 `Agent` 호출 인자 `model: "sonnet"`으로 띄우자 `claude-sonnet-5-5`로 실행되었다(시험 A. T15·T17·T19·T20). 같은 때 오케스트레이터는 `claude-opus-5-5`였다(T22). 따라서 정의 파일을 `inherit`로 둔 채 오케스트레이터가 단계마다 호출 인자로 모델을 정할 수 있다. 호출 인자가 정의 파일보다 앞선다는 공식 문서(F2)와 맞는다. 호출 인자에는 별칭만 시행했고 모델 ID를 직접 받는지는 확인하지 못했다.
  - **② `model: inherit`의 상속(실측. 오케스트레이터가 Opus 5.5인 경우)**: 호출 인자 없이 띄운 서브에이전트(시험 B, 이 실험 세션)는 오케스트레이터와 같은 `claude-opus-5-5`로 실행되었다(T16·T18·T19·T21·T22). 오케스트레이터가 Opus가 아닐 때 따라 바뀌는지는 시행하지 않았다.
  - **③ 실행 모델 확인 수단(실측. 한계 있음)**: Claude Code의 세션 기록 파일로 자기 보고와 별개로 실행 모델을 확인할 수 있다. 서브에이전트는 `~/.claude/projects/<프로젝트>/<세션 ID>/subagents/agent-<agentId>.jsonl`의 응답 `model` 값(예: `"model":"claude-sonnet-5-5"`)과 같은 폴더 `agent-<agentId>.meta.json`의 요청 `model` 값(예: `"model":"sonnet"`. 호출 인자가 없으면 키가 없음), 오케스트레이터는 `~/.claude/projects/<프로젝트>/<세션 ID>.jsonl`의 `model` 값이다(T17~T22). 한계는 세 가지다. ⓐ 세션 기록 파일은 사용자 PC의 저장소 밖 경로이며 저장소에 남지 않는다 ⓑ 이번 대조는 문자열 검색으로만 했고 행 전체 구조는 열어 보지 않았다 ⓒ 판정서 머리말 `auditor.model`은 여전히 세션이 적는 값이므로, 세션 기록 파일과 대조하지 않으면 자기 보고값이다. `/tasks`(F5)와 `claude -p` JSON 출력(F10·F11)은 시행하지 않았다.
  - **별칭과 모델 ID(실측 1건과 문서 근거)**: 별칭 `sonnet`은 `claude-sonnet-5-5`로 풀렸다(T19). 별칭은 시간이 지나며 최신 권장 버전으로 바뀌고 버전을 고정하려면 전체 모델 ID를 쓴다(F7). 호출 인자나 정의 파일에 주 대화와 같은 계열의 별칭을 적으면 별칭이 가리키는 버전이 아니라 주 대화의 정확한 모델로 실행된다(F3).
  - **강제 설정(문서 근거)**: `CLAUDE_CODE_SUBAGENT_MODEL_FORCE`가 켜져 있으면 정의 파일 `model`이 무시되고 호출 인자를 줄 수 없다(F4). 이 저장소의 `.claude/settings.json`에는 `model`·`env` 키가 없다(T1). 실행 환경의 변수 값은 확인하지 못했다.
  - **effort(문서 근거)**: 서브에이전트 정의 파일에 `effort`를 적을 수 있고 세션 effort보다 앞선다(F9). 정의 파일에 `effort`가 없을 때 서브에이전트가 세션 effort를 이어받는지는 문서에 없고 실측하지 못했다.
  - **D12 범위**: 시험 세션은 중급(Sonnet)만 썼고 최고급은 쓰지 않았다.
- **정규 경로로 복사·이동하지 않았다는 확인**: 실험 파일은 `Lab/REQ-022_모델지정/실험기록_v01.md`, `실험기록_v02.md` 두 개이며 정규 경로로 복사·이동하지 않았다. 커밋 전 검사가 두 파일을 `Lab/` 변경으로 분류했다(3절). 시험 A·B 세션이 파일을 만들지 않았다는 것은 오케스트레이터 보고다.
