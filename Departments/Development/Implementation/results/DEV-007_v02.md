## 5. 확인하지 못한 항목
- **이 PC의 Git 줄바꿈 설정(`core.autocrlf`) 값**: 확인 불가. `git config`는 `allow`에 없어 실행하지 않았다. 적용본은 LF이며, 시험 중 `LF will be replaced by CRLF` 경고가 나왔다. 줄바꿈 차이가 규칙 동작에 영향을 주지 않음은 3.1절 시험(적용본을 그대로 복사해 사용)으로 확인했다.
- **v01에서 권한 확인 요청이 뜬 원인**: 확인 불가(3절 아래 첫 항).
- **단위 테스트 종료 코드**: pytest 종료 코드는 5(수집된 테스트 없음)다. 이 안건은 테스트 대상 코드를 바꾸지 않으며 커밋 전 검사도 단위 테스트를 생략했다. `Workflow/03_라이프사이클` 구현 행 「테스트 통과」를 이 상태로 충족한 것으로 볼지는 최종 판정이 정한다.
- **`git clean -fdX`가 `ask`에 없는 점**: 개정 규칙과 어긋나지 않으나, 에이전트가 이 명령을 실행하면 확인 없이 파일이 지워진다. 대응 여부는 이 안건 범위(`.claude/` 미포함) 밖이므로 판단하지 않았다.
