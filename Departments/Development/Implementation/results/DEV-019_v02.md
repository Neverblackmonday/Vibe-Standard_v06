  - **메시지 구분**: 기록에 나온 막힘은 두 가지 메시지로 나뉜다. ⓐ 「This command requires approval」, 「The following part requires approval: …」, 「This command changes directory before running a version-control command …」, 「Command contains subexpressions」: 명령이 `allow` 규칙과 기본 읽기 전용 명령 어디에도 맞지 않아 확인 요청이 된 것이다. 이 세션에서 모두 재현했다. ⓑ 「Permission to use Bash has been denied.」, 「Permission to use PowerShell has been denied.」: 이 세션에서는 한 번도 나오지 않았다.
  - **원인 A — `git -C <경로>`**: `Bash(git status*)` 등은 명령 앞부분 문자열로 맞추므로 `git -C <경로> status`에 맞지 않고, 기본 읽기 전용 명령으로도 인정되지 않는다(T3, T5, T19. `-C`를 뺀 T2·T4·T8b·T24는 실행됨). 공식 문서 「What a Bash rule doesn't match」.
  - **원인 B — 복합 명령의 일부가 허용 밖**: 복합 명령은 하위 명령마다 따로 검사한다. 하위 명령 하나가 허용 밖이면 전체가 확인 요청이 된다(T0, T5, T14). 모든 하위 명령이 허용 대상이면 실행된다(T4, T6, T12). 공식 문서 「Compound commands」.
  - **원인 C — `cd <다른 폴더>`와 `git`의 결합**: 하위 명령이 모두 허용 대상이어도 확인 요청이 된다(T8. `cd` 없이 실행한 T8b는 실행됨). 공식 문서 「Read-only commands」의 「`cd` with `git`」.
