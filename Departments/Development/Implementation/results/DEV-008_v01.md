### 4.1 1행: `auditor.model`
- **구분**: 실측 불가.
- **사유**: `auditor.model`은 판정 세션의 자기 보고값이다. 실제 실행 모델을 보여 주는 기록(Claude Code가 PC에 남기는 세션 기록, API 사용 기록)은 저장소 밖에 있어, 조회하면 권한 확인 요청이 생긴다(`Workflow/03_라이프사이클` 「중단 조건」 5항).
- **대표님 확인 절차**:
  1. 이 파이프라인 실행이 끝난 뒤, 그 실행의 Claude Code 세션 기록에서 품질 서브에이전트(`quality`) 응답마다 기록된 모델 값을 찾는다.
  2. 세션 기록을 찾지 못하면 API 사용 기록(콘솔의 사용량 화면 등)에서 판정 시간대(`RES-008-EC_v01`·`v02`, `RES-008_v01`의 `created`·판정 시각 전후)의 모델별 사용 내역을 확인한다.
  3. 세션 기록의 위치와 형식은 이 결과서 작성 때 확인하지 않았다(확인 불가). 저장소 밖이기 때문이다.
- **판단 기준**: 판정 시간대의 품질 서브에이전트 응답 모델이 모두 `claude-opus-5-5`이면 「확인」. 기록에 모델 값이 없거나 기록을 찾지 못하면 「확인 불가」로 남긴다.
- **참고**: 없음.

### 4.2 2행: 서브에이전트의 `AGENTS.md` 자동 읽기
- **구분**: 실측 불가.
- **사유**: 서브에이전트가 자기 입력에 무엇이 들어 있었는지를 스스로 관찰한 내용은 자기 보고값이어서 기계로 확인할 수 없다.
- **대표님 확인 절차**: 이 실행의 세션 기록에서 개발·품질 등 서브에이전트의 첫 입력에 `AGENTS.md` 본문이 들어 있는지, 그리고 그 전에 `AGENTS.md`를 읽는 도구 호출(`Read`)이 없는지 확인한다. 세션 기록의 위치와 형식은 확인 불가(4.1절 3항).
- **판단 기준**: 첫 입력에 `AGENTS.md` 본문이 있고 그 전에 읽는 도구 호출이 없으면 「자동으로 읽음」. 기록을 찾지 못하면 「확인 불가」.
- **참고(자기 관찰, 실측 결과로 세지 않음)**: 이 개발 서브에이전트의 첫 도구 호출 전 입력에는 시스템 안내 블록 안에 사용자 전역 `CLAUDE.md` 본문, 저장소 `CLAUDE.md` 본문(`@AGENTS.md` 한 줄), 저장소 `AGENTS.md` 본문(「바이브 코딩 에이전트 거버넌스 규정 (AGENTS.md)」부터 「3. 개정 이력」까지)이 들어 있었다. 이 세션은 `AGENTS.md`를 `Read` 도구로 읽지 않았다.

### 4.5 6행: 하위 폴더 `CLAUDE.md`·`.claude/` 자동 로드

- **사유**: 저장소 안에 실측용 `CLAUDE.md`를 두면 이후 세션(최종 판정 포함)이 그 파일을 불러올 수 있어 실측이 다른 단계를 오염시킨다. 자동 로드 여부도 자기 관찰로만 알 수 있다.
- **대표님 확인 절차**:
  1. 저장소 밖 임시 폴더(예: `D:\tmp\claude_probe\`)를 만들고, 루트에 `CLAUDE.md`(내용 예: 「실측용 루트 파일」)를 둔다.
  2. 하위 폴더 `sub\`에 확인용 문자열(예: `PROBE-6-7Q2K`)만 담은 `CLAUDE.md`와, 아무 내용의 `sub\note.txt`를 둔다.
  3. 임시 폴더 루트에서 Claude Code를 실행해 「`sub/note.txt`를 읽고 내용을 알려 달라」고만 지시한다.
  4. 응답이나 세션 기록의 입력에서, `sub\CLAUDE.md`를 읽는 도구 호출 없이 확인용 문자열이 나타나는지 확인한다.
  5. `.claude/`의 자동 로드는 같은 방식으로 `sub\.claude\settings.json`에 `deny` 규칙 `Write(blocked.md)`를 두고, 임시 폴더 루트에서 `sub/blocked.md` 쓰기를 지시해 거부되는지 확인한다. 4.3절 실측에서 경로 구분자 없는 규칙이 하위 폴더에도 적용되었으므로, 규칙 경로의 기준 위치와 관계없이 이 규칙이 읽히면 거부된다. 루트에는 `.claude/`를 두지 않는다.
  6. 세션 기록의 위치와 형식은 확인 불가(4.1절 3항).
- **판단 기준**: 도구 호출 없이 확인용 문자열이 나타나면 「하위 `CLAUDE.md` 자동 로드됨」, 나타나지 않으면 「이 조건에서 자동 로드되지 않음」. 5항의 쓰기가 거부되면 「하위 `.claude/` 적용됨」. 응답과 기록 어느 쪽으로도 판단할 수 없으면 「확인 불가」.
- **참고**: 없음.
